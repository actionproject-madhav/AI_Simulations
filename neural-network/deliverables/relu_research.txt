ReLU Activation Research

Why ReLU is preferred over sigmoid:
Relu solves the vanishing gradient problem. Sigmoid saturates at 0 or 1 that makes gradient very small, when x is large.
RELU gradient is either 0 or 1 hence it doesn't vanish for large inputs.
RELU is also straightforward to compute as it's just max(0,x) unlike sigmoid which is exponential
ReLU seems to make deep neural networks faster, and easier to converge with better accuracy



Leaky ReLU

Problem with basic ReLU: neurons can "die" if they always output 0.
Once a neuron's weights push it negative, gradient is 0, so it never recovers.

Leaky ReLU fixes this:
  f(x) = x if x > 0
  f(x) = αx if x ≤ 0     (where α is small, like 0.01)

This gives a small gradient even for negative inputs, so neurons can recover.
Trade-off: slightly more computation, but prevents dead neurons.
